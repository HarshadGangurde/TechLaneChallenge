# Fonts used in the roadmap PDF

The same families as the website (loaded there through `next/font/google`), embedded here so the
server can use them when it draws the PDF: Outfit ExtraBold (headings), Inter Medium/SemiBold
(body text), JetBrains Mono Bold (small labels). Latin subsets, from Fontsource. All three are
licensed under the SIL Open Font License 1.1 (see the OFL-*.txt files).
